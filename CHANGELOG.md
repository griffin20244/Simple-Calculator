# Changelog

Notable changes to Simple Calculator are documented here.

## [2.0.0] - 2026-10-19

### Added
- Complete dependency-free browser calculator rebuild
- Responsive dark UI and keyboard shortcuts
- Session calculation history
- Arithmetic parser that avoids `eval()`
- Project documentation, copyright notice, and GPL-3.0-only licensing

### Changed
- Reworked the interface and interaction flow for a cleaner, more accessible experience
