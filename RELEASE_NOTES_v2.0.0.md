# Simple Calculator v2.0.0

A fresh, dependency-free rebuild of Simple Calculator.

## Highlights
- Responsive dark interface
- Addition, subtraction, multiplication, division, and percentage
- Keyboard shortcuts
- Recent calculation history
- Arithmetic parsing without `eval()`
- Works offline with no third-party dependencies

## Installation
Download the source from this repository and open `index.html` in a modern browser. No build step is required.
