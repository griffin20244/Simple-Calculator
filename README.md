# Simple Calculator

A lightweight, modern calculator built with plain HTML, CSS, and JavaScript. It runs locally in your browser, works offline, and has **no external dependencies**.

![Version](https://img.shields.io/badge/version-2.0.0-a8f06a?style=flat-square)
![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg?style=flat-square)
![Dependencies](https://img.shields.io/badge/dependencies-none-success?style=flat-square)

## Features

- Responsive dark interface with keyboard support
- Addition, subtraction, multiplication, division, and percentage
- Calculation history for the current session
- Clear, sign toggle, decimal input, and backspace via keyboard
- Arithmetic parser implemented without `eval()` or dynamic code execution
- No network requests, analytics, cookies, or third-party packages

## Run it

1. Download or clone this repository.
2. Open `index.html` in any modern browser.
3. Start calculating — no installation or build step required.

```bash
git clone https://github.com/griffin20244/Simple-Calculator.git
cd Simple-Calculator
```

Then open `index.html` in your browser.

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| `0–9`, `.` | Enter a number |
| `+`, `-`, `*`, `/` | Arithmetic operators |
| `%` | Percentage |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete the last character |
| `Esc` or `Delete` | Clear |
